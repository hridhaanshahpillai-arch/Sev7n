# 2D games (v0.5 alpha)

Sev7n makes 2D games with the same tools as 3D ones. A 2D game is a scene seen
**flat**, through an orthographic camera. Switch that camera back to perspective at any
time (even while playing) and the same scene becomes 3D: sprites turn into cards
standing in a 3D world.

## Setting up a 2D scene

1. Select the **Main Camera**. In the Inspector, tick **2D (flat)**.
2. Click **Face the 2D plane**. The camera now looks straight down -Z at the X/Y plane,
   where 2D games live. **Size** is how many units it sees above and below its center.
3. In the **Scene** view, click the **2D** button so you edit flat too. Drag with the
   right or middle mouse button to pan, and use the wheel to zoom.

In 2D, +X is right and +Y is up. Use Z to put things in front of or behind each other
(higher Z is closer to the camera), or use a sprite's **Order**.

The Scene view opens in 2D by itself when the game's camera is a 2D one.

## Sprites

Drag a picture into the Scene view to make a sprite. In the flat view it lands exactly
where you drop it. Sprite Renderer settings:

| Setting | What it does |
|---------|--------------|
| **Picture** | The image. PNG see-through parts stay see-through |
| **Size** | Height in units; the width follows the picture |
| **Pixel art** | Keep pixels sharp (turn on for pixel art, and for sprite sheets whose frames bleed into each other) |
| **Remove bg** | Make a solid background color see-through (the color of the top-left pixel), for retro sprite sheets on blue or magenta |
| **Flip X / Flip Y** | Mirror it, e.g. a character facing left |
| **Order** | Sprites at the same distance: higher numbers are drawn on top |
| **Sheet columns / rows** | Cut a sprite sheet into frames (see below) |
| **Frame** | Which frame to show. Click a frame in the preview to pick it |

## Sprite animation

A **sprite sheet** is one picture with many frames in a grid. Set **Sheet columns** and
**Sheet rows** to match it. The preview shows the frames, numbered left to right, then
top to bottom, from 0.

### The Sprite Editor

For exact control, select a sprite and click **Open Sprite Editor** in the Inspector.
It shows the sheet big, with every frame outlined and numbered.

| Tool | Key | What it does |
|------|-----|--------------|
| **Select** | V | Click a frame. Drag it to move; drag its corners or edges to resize; drag the green dot to move its pivot |
| **Rectangle** | R | Drag to draw a new frame |
| **Polygon** | P | Click corner points to crop any shape with straight edges, diagonals included. Hold **Shift** for perfectly straight or 45° edges. Click the first point (or press Enter) to finish; Backspace removes the last point |
| **Pivot** | O | Click where the selected frame stands. Frames are lined up by their pivots |

- **Find frames** finds every picture on the sheet automatically. **Grid...** cuts it into equal
  cells (by number of columns and rows, or by cell size, with an offset and gaps), skipping empty cells.
- With a frame selected: type exact **X / Y / Width / Height / Pivot** numbers, move it **Earlier**
  or **Later** (the order animations play in), **Join next**, **Trim** it to its pixels,
  **Duplicate** or **Delete** it.
- Mouse wheel zooms (a pixel grid appears up close), right- or middle-drag pans, arrow keys
  nudge the selected frame (Shift = 10 pixels), **Ctrl+Z** undoes.
- The **Preview** plays the frames in order, exactly as the game will show them.

Frames drawn by hand show exactly what's inside their rectangle or polygon.

### Sheets that aren't an even grid

Many sheets (especially ripped or hand-made ones) have frames of different sizes, placed
unevenly. Cutting those into a grid slices straight through the pictures. Instead, click
**Find frames automatically**: Sev7n finds each separate picture on the sheet, keeps loose
bits (a flying shell casing, sparks) with their frame, and numbers the frames in reading order.
If the sheet has a solid background color, **Remove bg** is turned on for you first.

- Each frame shows only its own pixels, even where neighbouring frames overlap on the sheet.
- Frames are lined up by their main body (the hand, the feet), so a flash or casing off to
  one side doesn't make the sprite jump around.
- If a frame comes out in two pieces, click the first piece in the preview and press
  **Join with next**. **Remove frame** drops one; **Use a grid** goes back to columns and rows.

Then **Add Component → Sprite Animator** and make animations:

| Setting | What it does |
|---------|--------------|
| Name | What scripts call it, e.g. `run` |
| From frame / To frame | The frames it plays (To lower than From plays backwards) |
| Frames / sec | How fast |
| Loop | Start again after the last frame |
| Plays first | The animation that plays when the game starts |

Click **Preview** to watch it in the editor. In scripts:

```seven
entity.play("run")          // switch animation (playing the current one again does nothing)
entity.animation            // the one playing now
entity.animationDone        // true once a non-looping animation has finished
entity.flipX = true         // face left
entity.frame = 3            // show one frame (without an animator)
```

## Tilemaps

A tilemap builds a level from a **tileset**: one picture holding many tiles in a grid.

1. **Create → Tilemap**.
2. Pick the **Tileset** picture. Set **Columns** and **Rows** to how many tiles it has
   across and down.
3. Click a tile in the palette, then **click or drag in the Scene view** to paint.
   **Shift** + click erases, or pick the **Eraser**. Press **Esc** or **Stop painting** when done.

| Setting | What it does |
|---------|--------------|
| Tile size | How big each tile is, in units |
| Pixel art | Keep pixels sharp (on by default) |
| Solid | Rigidbodies stand on the tiles and bump into them ([physics](PHYSICS.md)) |

Cell (0, 0) covers 0 to 1 on X and Y (with tile size 1), and cells count up to the right
and upwards. Tilemaps are drawn behind sprites at the same distance.

In scripts:

```seven
var level = find("Level")
level.tile(3, 0)            // the tile number in cell (3, 0), or none if it's empty
level.setTile(3, 0, 5)      // paint tile 5 there
level.setTile(3, 0, none)   // clear it
```

## A complete platformer player

Give a sprite a **Box Collider** and a **Rigidbody**, paint a solid tilemap floor, then
attach this:

```seven
behaviour Platformer {
    var speed = 5
    var jump = 7

    func update(dt) {
        var move = 0
        if key("a") or key("left")  { move -= 1 }
        if key("d") or key("right") { move += 1 }
        entity.velocity.x = move * speed
        if move != 0 { entity.flipX = move < 0 }

        if keyPressed("space") and entity.grounded {
            entity.velocity.y = jump
        }

        if move != 0 { entity.play("run") } else { entity.play("idle") }
    }
}
```

## From flat to 3D

The camera's projection is just a setting, so a game can change it whenever it likes:

```seven
var camera = find("Main Camera").camera
camera.orthographic = false      // 3D perspective: depth appears
camera.fieldOfView = 50
camera.orthographic = true       // back to flat
camera.size = 8                  // zoom out (2D)
```

Sprites with **Billboard** on keep facing the camera in 3D, like characters in classic
3D games.
